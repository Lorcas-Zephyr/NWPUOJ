# 比赛代码查重

入口：比赛管理 → 代码查重。比赛结束后点击“一键查重”，后台排队运行，关闭页面不影响任务。历史任务、分组结果和报告会保留；可重复查重，每次生成新的历史记录。

权限沿用当前比赛的管理权限，包括创建者、有效的指定管理员、全站管理员，以及基地比赛的管理范围。普通选手不能读取任务、相似代码或下载报告；每次读取重新检查权限。报告存入独立的私有 Docker volume `nwpuoj_plagiarism_reports`，不在静态资源或公开图床目录。

## 比较规则

- 只使用该比赛开始时间（含）到结束时间（不含）的提交，排除赛后练习。
- 每人、每题、每种语言家族选择最后一次 AC；没有 AC 时选择最后一次非空源码提交。使用 v2 保存的原始源码，旧提交回退到原代码列。页面展示所选提交编号，因此能核查实际比较版本。
- C 和 C++ 使用 C++ 解析器一起比较；Python 3 和 PyPy 3 一起比较。Java、JavaScript、TypeScript、Go、Rust、Kotlin、C# 各自比较。
- Python 2、Pascal、Ruby、Haskell、提交答案包及其他不支持的类型不参与比较，并显示跳过数量。JPlag 不保证支持每种语言的全部最新语法，解析失败会在分组结果中显示，不能据此判为无相似。
- 不同题目、不同语言家族不比较，同一选手不与自己比较。每个分组至少两人；使用 JPlag 默认最小 token 数，短代码可能不具备足够 token。
- 原始报告保留平均相似度至少 30% 的比较；页面默认显示至少 50%，可筛选分组、相似度并翻页，每页 50 对。
- 支持并排查看源码、跳转相似片段。分组提供“下载网页报告”：保存为 HTML 后双击用浏览器离线打开，无需安装 JPlag，包含该分组全部已保存比较、源码、相似片段和未完成检测说明，支持搜索、相似度筛选和分页。保留“原始 .jplag”下载供专业查看器使用。相似度不是作弊或 AI 使用的判定，不自动改成绩、Rating 或封禁用户。

## 运行环境

首次部署先运行 `bash custom/scripts/install-jplag.sh`，安装官方 JPlag 6.3.0 和 Temurin JDK 25，下载均校验固定 SHA256。Java 语言解析需要完整 JDK。`custom/tools/jplag` 不入 Git，运行时只读挂载到 `/opt/jplag`。

新挂载需 `docker compose up -d --no-deps web` 生效。数据表 `contest_plagiarism_job` 自动初始化。

全站同时只运行一个任务（数据库命名锁），分组依次处理；JVM 堆限制 2 GiB，活动处理器数 2，nice 优先级 10，每组最多 15 分钟。单场预检限制 100000 次提交或原代码总量 256 MiB，单组最多 1500 人，超出会明确报告失败。查重不编译或运行选手代码，不把代码发送到第三方。

同一比赛已有活动任务时重复点击返回同一任务；JSON 请求标识可穿过会清理自定义头的外网网关。服务重启后，排队任务继续，已中断任务标为失败并保留历史，管理员可重新点击查重。网页报告从已存档的结果生成，旧任务也可使用，无需重新查重；在私有目录缓存，每次下载仍检查当前比赛管理权限。源码只内嵌一次，匹配信息按行压缩；单次读取比对 JSON 最多 512 MiB、源码总量最多 64 MiB，超出可继续在网页逐项查看。报告内无外部资源或联网请求，选手代码作为文本显示并设置内容安全策略。

删除比赛会级联删除查重数据库记录；私有报告文件暂不自动删除，供站长备份或清理。请将报告 volume 纳入与选手源码相同的备份和保留策略。

## 验证

- `NWPUOJ_JPLAG_ENGINE_TEST=1 node --test custom/tests/contest_plagiarism.test.js`：真实 JPlag 的 C/C++、Python、Java、解析失败和报告格式。
- `custom/tests/contest_plagiarism.mysql.test.js`：在 Web 容器设置 `NWPUOJ_PLAGIARISM_DB_TEST=1`，用连接级临时表覆盖测试涉及的表；验证权限、重复请求、任务执行、报告和中断恢复，不修改真实比赛。
- `NODE_PATH=/tmp/noj-ccsp-review-browser/node_modules node --test custom/tests/contest_plagiarism.browser.test.js`：真实 Chromium 在隔离页面验证一键查重、刷新、筛选、分页、代码高亮、移动端和请求头。
