# NWPUOJ v2.0.1 使用手册

本文面向参赛者、普通用户、题目维护者、比赛管理员和站点管理员。界面以中文为主，
本文中的菜单名称与 v2.0.1 实际页面保持一致。

## 1. 账号与全局界面

### 1.1 注册和登录

1. 打开 `/sign_up`，填写用户名、密码、邮箱、学号、姓名和学院。
2. 学号为 10 位数字。普通账号之间学号必须唯一；比赛临时账号可在各自比赛作用域内
   使用与普通账号相同的学号。
3. 注册完成后按站点要求验证邮箱。未验证邮箱时，部分内容发布和消息功能可能不可用。
4. 登录后可在右上角头像菜单进入个人主页、账号设置、剪贴板、管理后台和退出登录。

密码遗忘时，从登录页进入“忘记密码”，通过邮件中的一次性链接重置。重置密码、禁用
账号或管理员修改关键身份后，既有会话会被吊销。

### 1.2 导航和显示模式

桌面左侧导航包含首页、题库、比赛、评测、排名、公告、讨论和帮助。移动端使用顶部菜单
和底部主导航。快捷跳转按钮可按页面名称筛选入口，不会搜索题目内容。

右上角太阳/月亮按钮切换浅色和深色模式。选择保存在当前浏览器。代码块、评测源码、
测试点和编辑器会随主题切换。所有页面固定保留滚动条位置，短页面和长页面不会左右跳动。

## 2. 题库与做题

### 2.1 查找题目

进入“题库”后可以组合使用：

- 题号或标题关键词；
- 来源：主题库、UOJ、HDU、POJ 等；
- 状态：未尝试、已尝试、已通过；
- 标签和标签交集；
- 排序及分页。

标签由管理员选择类型，系统根据类型自动使用统一颜色。标签按钮只负责筛选，不会修改
题目。题库不保存本地“视图”，刷新后以 URL 中的筛选条件为准。

### 2.2 阅读题面

题面是一个连续的 Markdown 文档，题目描述、输入、输出、样例和提示不再拆成多个视觉卡片。
页头左侧显示题型、时间限制、内存限制、输入输出和评测方式。比赛内题目沿用同一题面，
但受比赛开始时间和可见性规则限制。

### 2.3 提交代码或答案

1. 在题目页点击“提交”。
2. 选择语言。比赛内只显示比赛允许的本地语言。
3. 在白色代码编辑器中输入或粘贴源码。编辑器不显示缩略图；加载失败时会自动提供
   可访问的文本框。
4. 提交答案题使用文件选择控件上传答案文件。
5. 点击“提交评测”。按钮锁定和加载状态表示请求已经发出，不要重复点击。

提交创建后进入评测详情。列表和详情通过事件流更新状态；断线时会保留当前内容并进行
有上限的重连，不需要手动连续刷新。

## 3. 评测记录与详情

### 3.1 筛选评测

“评测”页面支持题号、提交者、语言、状态和分数区间筛选。登录用户可以用“全部 / 我的”
快速切换范围。比赛中的评测页只展示该比赛允许看到的数据。

结果颜色在评测列表、评测详情和个人主页保持一致。结果文字是可点击链接时仍保留结果
颜色，不会统一变成蓝色。

### 3.2 查看详情

评测详情可能包括源码、编译信息、资源用量和测试点。可见范围取决于提交所有者、题目
策略、比赛阶段和 `judge:read` 权限。比赛冻结或隐藏结果时，分数、代码、测试点和诊断
不会提前泄露。

“复制代码”优先使用浏览器剪贴板 API；浏览器不支持或权限被拒绝时使用兼容复制方式。
仍无法复制时，可选中源码区域手动复制。

管理员的作弊、取消、撤销和恢复操作需要相应能力并产生审计记录。批量重测在后台形成
一个可跟踪任务，可查看进度、取消或重试失败项。

## 4. 比赛

### 4.1 比赛列表和详情

进入比赛时默认打开“详情”。子页面统一为：

1. 详情；
2. 题目；
3. 排行榜；
4. 提交记录；
5. 参赛者。

详情页展示比赛信息、公告、状态、起止时间和报名入口。普通用户可以查看公开参赛者用户名；
姓名、学号、学院、删除和恢复操作只在比赛管理的“报名管理”中出现。

所有用户界面将 ICPC 模式称为“ACM”。内部 Rating Profile 的 `icpc` 标识仅用于持久化，
不代表另一个比赛模式。

### 4.2 报名和参赛

公开比赛按配置开放报名。登录后点击“报名”，成功后可以在允许的时间查看比赛题目并提交。
迟到报名是否开放由比赛管理员设置。被管理员移出的用户不能继续以参赛者身份访问私有比赛，
管理员可以在报名管理中恢复。

比赛临时账号由管理员从 CSV 批量创建。临时账号在指定比赛内有效，到期后自动禁止登录。

### 4.3 排行榜与 Rating

ACM 排行榜按通过题数、罚时和稳定并列规则计算。冻结期间管理员可看实时榜，公开榜保持在
冻结版本；解冻或结束后生成新版本。

Rated 比赛结束后，管理员先处理作弊和无效提交，再在后台 Rating 页面点击一键计算。计算按
比赛时间顺序执行。Rating 发布后，受影响参赛者会收到包含赛前、赛后和变化值的通知。
若删除较早的 Rated 比赛，后续比赛会按时间顺序重新计算，通知会说明删除的比赛和最终变化。

## 5. 个人与内容功能

### 5.1 个人主页和账号设置

个人主页展示用户名、用户名颜色、可见牌子、Hit 信息、Rating 折线图及实际参加过的比赛链接。
右上角头像与个人主页使用同一头像来源。

账号设置可修改邮箱、签名、显示偏好、密码和头像。普通用户已经提交的学号、姓名和学院不能
自行修改；有用户管理权限的管理员可按权限处理。用户名牌可自行隐藏，全站管理员也可全局
关闭牌子功能。

### 5.2 通知、站内信和关注

通知中心保存比赛 Rating 变化、内容审核和系统事件。可单条标记已读、全部已读或删除。
站内信支持会话、新消息和接收设置。关注页展示关注、粉丝和互关关系。

动态发布功能已经移除，不会在首页或个人页显示动态流。

### 5.3 题解、讨论、剪贴板和工单

- 题解：作者创建 Markdown 题解并提交审核。审核拒绝必须写清修改原因；其他常规系统操作
  不要求手写原因。
- 讨论：可以浏览公开讨论、发帖和回复。与私有题目关联的讨论遵循题目可见性。
- 剪贴板：保存 Markdown 内容，可设为私有、公开或使用限时分享链接。
- 工单：按类别和子类型提交问题，可关联题目、比赛或提交；处理进度显示在时间线中。

编辑器左侧只有一个滚动区域，右侧预览与左侧保持同高并同步滚动。关闭过期草稿恢复提示后，
相应草稿会被删除，不应在每次进入帮助页时重复提示。

## 6. 后台管理

只有全站管理员和站长能看到完整后台导航。专项管理员只看到自己拥有能力的工作区，不会因为
拥有“管理用户”能力而自动获得完整后台。

### 6.1 概览、用户和权限

- 概览：查看站点健康、风险和核心统计，不再显示已经完成的迁移面板。
- 用户：搜索用户、编辑资料、查看账号状态或删除用户。系统账号、站长和不允许管理的同级
  管理员受到保护。
- 权限：授予或撤销作用域角色。高风险权限变更要求近期登录并产生审计记录。
- 用户名牌：配置全局开关、牌子授权、禁用和展示状态。

### 6.2 题目与标签

从题库点击“添加题目”直接进入新建题目页。题面使用一个完整 Markdown 字段。新题先形成草稿
版本，审核后发布；发布后的修改形成新草稿，不会直接覆盖公开版本。

新建标签时必须选择标签类型，颜色由系统自动判定。已有标签在未被题目引用时才可删除。
测试数据上传、删除和快照操作受路径校验、文件类型和大小限制保护。

### 6.3 比赛和报名管理

新建比赛分为基本信息、题目/管理员、赛程/规则和确认四步。草稿比赛允许暂不选择题目；发布
或开始前必须至少有一道题。比赛开始后关键计分配置和题目快照锁定。

公共“参赛者”页只读；删除、恢复、导出报名信息、批量创建临时账号和排行榜重建均在比赛
管理的报名管理页完成。拥有比赛管理权限的管理员可以在比赛进行中删除比赛，删除使用一个
事务清理比赛提交、报名、排行榜、快照和相关任务，并触发必要的 Rating 重算。

### 6.4 内容、评测和维护

- 公告：生效公告置顶并按重要性排序；已结束公告排在其后并按开始时间排序。
- 轮播：上传经过实际文件内容校验的 JPG、PNG、WebP 或 GIF。
- 帮助页：统一 Markdown 编辑和发布，草稿恢复遵循编辑器规则。
- 题解审核：批准或写明拒绝原因。
- Rating：只展示计算状态、未计算比赛和一键计算入口。
- 批量重测：按条件创建统一任务并跟踪进度。
- 评测服务：查看 Daemon/Runner、队列、CPU、内存、PID、OOM 和启动时间，并按权限重启
  单个 Worker。
- VJudge/维护工具：管理 UOJ、HDU、POJ 连接，执行批量导入，选择导入后是否公开，以及
  冲突时跳过或覆盖。
- 系统配置和友链：只暴露允许修改的字段，密钥不会显示在页面中。

## 7. 常见问题

### 页面图标空白

先硬刷新浏览器并确认 `/self/lucide-1.27.0.min.js` 返回 200。提交页会在 Monaco 加载前加载
图标库，正常情况下不依赖编辑器初始化。

### 提交一直显示等待

先查看评测详情，再联系评测管理员检查后台“评测服务”和 RabbitMQ `task` 队列。不要重复
提交相同代码制造更多排队任务。

### 比赛看不到题目

确认已报名、比赛已开始、账号未被移出、比赛不是私有且当前账号具有访问作用域。管理员可在
报名管理中检查状态。

### 操作提示 409、412 或 428

这通常表示资源已被其他管理员修改或页面版本过期。刷新页面获取新的 ETag，再重新确认操作。
不要绕过提示重复发送旧请求。

### 页面提示需要重新登录

删除、权限、配置、Rating 和重启等高风险操作要求近期登录。退出后重新登录，再执行操作。
