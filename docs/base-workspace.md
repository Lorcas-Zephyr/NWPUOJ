# 基地工作区

实现日期：2026-09-24。

## 入口与范围

- 首页操作区、侧边导航增加“基地”。只有基地成员、站长和全站管理员可见。
- `/base/problems`：基地题库；`/base/contests`：基地比赛；`/base/submissions`：提交记录；`/base/members`：成员管理。
- 题目和比赛继续复用原有编辑、上传、评测、报名、榜单和通知流程，不新增验题反馈系统。
- 普通用户的基地身份不授予任何全站题目、比赛或用户管理权限。

## 权限规则

| 操作 | 基地成员 | 站长 / 全站管理员 |
| --- | --- | --- |
| 浏览基地内已公开题目、比赛 | 可以 | 可以 |
| 查看未公开题目 | 仅自己创建的 | 可以 |
| 创建题目、比赛 | 可以，仅限基地范围 | 可以 |
| 编辑、发布、归档题目 | 仅自己创建的 | 可以 |
| 批量公开、隐藏、归档、添加标签 | 仅自己创建的 | 可以 |
| 迁移题目至正式题库 | 不可以 | 可以 |
| 管理、删除比赛 | 仅自己创建的 | 可以 |
| 管理基地成员 | 不可以 | 可以 |

基地比赛只能选择基地内已公开的题目，可选择他人题目。Rated 在界面、写入服务和 Rating 计算路径均强制关闭。题面和评测数据仍使用全站既有的最新版本流程，不固定在创建比赛时的版本。

公开表示“基地内公开”，不进入普通题库、普通比赛列表、首页比赛列表或普通题单。比赛结束不会解除基地成员限制。已被基地比赛引用的题目须先从比赛移除，再取消公开或归档，避免通过比赛绕过未公开限制。

基地比赛只允许基地成员参赛，不支持生成临时比赛账户或启动 AI 参赛。报名管理仍可使用已有账户、班级和学号 CSV，但被添加者必须先成为基地成员。

移除成员只撤销访问权限，不删除账号、题目、比赛、提交或历史报名。原作者也不能继续访问基地资源；重新加入后恢复。权限检查覆盖题目和比赛详情、API、提交源码、下载令牌、异步任务、历史操作响应和活动事件流。

## 提交记录与手机布局

- 基地提交记录展示基地题库的练习提交，复用全站评测列表的语言、颜色、筛选、分页和实时状态更新。
- 支持题号、提交者、语言、状态、分数以及“全部 / 我的”筛选；翻页和清空筛选仍留在基地。
- 仅基地成员、站长和全站管理员可访问；他人未公开题目的记录不显示。比赛提交仍在对应比赛内查看，沿用报名、赛时和封榜规则。
- 题目正被未结束比赛使用时，普通基地成员仅可见自己提交或自己所出题目的练习记录，不能借基地汇总列表查看他人的练习结果。权限变化后实时流也会重新检查。
- 详情与源码沿用既有的本人、题目管理者、全站管理者或通过后查看的规则；基地练习提交成功进入“我的”提交记录，详情可返回基地列表。
- 手机端导航可横向滑动，搜索栏独占一行、按钮换行；导入表单纵向排列，宽表格只在局部滑动，保留所有信息和操作。

## 成员导入

- 搜索已有普通账户：用户名、UID、学号或姓名；支持多选。
- 搜索班级并多选，导入当前成员；后续班级变动不会同步。
- UTF-8 CSV，包含 `学号` 表头，每行一个 10 位学号，最多 1000 行 / 1 MB。
- 不新建账号，排除临时比赛账户、AI 账户和无需加入的全站管理员。
- 返回新增、已存在和失败结果；CSV 行号、无效学号、重复、未匹配、多账户匹配分别列明。
- 成员列表每页 100 人，支持搜索、单人移除和本页多选移除。写入与审计在同一事务中完成。

## 批量操作与迁移

基地题库的勾选列宽度、全选、已选数量、批量下拉菜单和确认弹窗沿用普通题库样式。公开、隐藏、归档和添加标签复用普通题库接口及逐题权限检查，不会因批量操作扩大管理范围。

站长和全站管理员可从每道题的操作按钮、题目管理菜单或批量菜单执行“迁移至正式题库”：

- 创建独立的正式题库副本，基地原题及其提交不删除、不改归属。
- 复制最新题面、题目类型、评测设置（包括 Python / Java 倍数）、测试数据、附件和标签；上传者保留为原出题人，不改为执行迁移的管理员，不匿名。
- 新建正式副本默认未公开，不继承基地原题的公开状态；确认无误后可在正式题库手动公开。基地原题及其公开状态保持不变，已迁移的正式副本不会被自动取消公开。确认弹窗和完成提示均说明默认未公开。
- 不复制提交、统计或比赛关联。基地原题后续保存的最新题面、评测配置、有效测试数据快照、附件和标签会单向同步至正式副本，通常约 5 秒，大数据包可能更久；正式副本的题号、作者、公开状态和历史提交不变，正式副本的编辑不会反向同步。已删除或归档的正式题目不会被自动恢复。
- 自动同步也覆盖已有迁移关系，持久化源内容指纹并在失败或服务重启后重试；未完成的 ZIP 上传不传播，历史评测快照不改写。同步失败记录在 `base_workspace_problem_sync.last_error` 和 Web 日志中，原题保存不会因副本同步失败而报错。
- 成功后显示“已迁移”及正式题库题号；重复或并发迁移不会创建多份有效副本。
- 正式副本删除或归档后，再次打开基地页面或返回该浏览器标签页时恢复“迁移至正式题库”。仅隐藏正式副本不会解除迁移状态。
- 当前支持本地传统题、交互题和提交答案题。
- 批量逐题返回成功、跳过与失败结果，失败不删除基地原题。

## 存储与部署

新增三张范围表：`base_workspace_member`、`base_workspace_problem`、`base_workspace_contest`，以及迁移映射表 `base_workspace_problem_migration`。不改动已有资源归属，不自动迁移现有普通题目或比赛。表由幂等初始化创建。

新模块、库和模板通过 Compose 只读挂载加载；更新时只需重建 Web 容器：

```sh
docker compose up -d --no-deps web
```

不需要重启评测机。Web 会话保存在 `nwpuoj_web_sessions` 命名卷，保留该卷和会话密钥后，重建不会清除未过期登录。

题面中的外部图片或既有公开图床链接仍遵循其原有公开链接规则；不要用公开图床存储需要保密的附件。
